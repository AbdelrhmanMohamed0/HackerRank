# HackerRank C Programming Challenges

This repository contains my solutions to a set of C programming problems from HackerRank. These problems cover a wide range of fundamental and intermediate programming concepts that I have practiced and mastered through hands-on coding.

## 🚀 Skills Demonstrated

Through solving these problems, I developed strong proficiency in:

- ✅ **C Programming Fundamentals**
  - Input/output handling
  - Data types and operators
  - Control flow: if, switch, loops

- 🔁 **Loops and Conditional Logic**
  - Implemented various patterns and number-based problems using nested and single loops
  - Applied decision-making using if-else and switch statements

- 🧠 **Functions and Modularity**
  - Created and used custom functions to break down problems and enhance code readability

- 📚 **Arrays and Memory Handling**
  - Performed operations like reversing, sorting, and dynamically managing arrays
  - Practiced 1D arrays and dynamic memory allocation techniques

- 🔗 **Pointers and Memory Access**
  - Worked on pointer arithmetic and value swapping
  - Developed understanding of memory management and references

- 🔤 **Strings and Tokenization**
  - Manipulated strings, compared, sorted, and tokenized them using standard C libraries

- 🧮 **Bitwise Operations**
  - Gained experience using bitwise AND, OR, XOR, and applying them in logical conditions

- 📊 **Problem Solving and Algorithmic Thinking**
  - Focused on writing clean, efficient, and optimized code
  - Solved algorithmic problems involving digit frequency, permutations, and more

## 📁 Repository Structure

Each `.c` file in this repository represents a separate problem, focusing on a specific concept or combined topics to reinforce learning.

## 📌 Goal

The main objective of this repository is to showcase my journey in mastering the C programming language by solving real-world challenges. It also serves as a reference for others who are learning C and want to practice structured problem-solving.
